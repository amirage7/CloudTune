CloudTune V0.7.4 智能音乐入库助手

搜索 → 试听 → 选择音源 → 核对歌名/歌手/封面 → 一键入库网易云。
试听不会下载或上传。任务中心可查看结果，失败后从已保存文件重试。
云盘、喜欢、封面分别记录状态；缺少封面可在本地库补充。

CloudTune 本地网页版 · Windows 10 / 11，64 位

1. 将压缩包解压到一个普通文件夹；不要直接在压缩包内运行。
2. 双击「启动 CloudTune.bat」，等待浏览器自动打开。
3. 首次使用连接自己的网易云账号。每个 Windows 用户有自己的记录。
4. 使用结束请关闭启动时出现的 CloudTune 运行窗口。
   也可以在该窗口按 Ctrl+C 正常停止服务，无需再双击其他文件。
   只关闭浏览器标签页不会停止服务，再次双击启动会打开原来的页面。

无需安装 Node、npm、yt-dlp、FFmpeg，无需购买服务器。
联网搜索、B站转换和网易云同步仍需要网络；本地音乐可离线播放。
此版本面向 Windows x64；手机不能直接运行这个压缩包。

音乐库、封面、设置和加密登录记录保存在：
%LOCALAPPDATA%\CloudTune\data
升级时停止旧版本，解压新版本，再启动即可。不要删除上述数据目录。

旧版升级：
先在旧项目文件夹运行新的启动入口一次，会自动复制该文件夹中的 data。
或者将旧版完整 data 文件夹复制到新解压文件夹，再首次启动。
已有固定用户数据时不会用旧版覆盖。旧 data 原文件会保留。
登录记录绑定原 Windows 账户，换电脑需要重新登录。

账号隔离以 Windows 用户为单位。同一个 Windows 账户共用同一个音乐库。
启动窗口会显示当前网页地址和数据路径。没有打开浏览器时可手动复制地址。
分享时只分享原始发布 ZIP，不要打包自己的 data 或用户数据目录。

只处理你有权使用的音频；各平台登录和媒体接口仍受其可用性影响。
第三方运行环境、工具及依赖的许可和来源见 third-party 文件夹。


搜索网络：启动时自动使用已有 HTTP/HTTPS 或 Windows 手动系统代理。
无需修改系统设置；本地网页直连。代理设置变化后关闭运行窗口再启动。
