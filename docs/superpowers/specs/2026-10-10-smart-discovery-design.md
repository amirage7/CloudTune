# CloudTune 智能音乐入库助手优化范围

依据引用会话中实际返回的用户选择整理。引用会话中的助手详细方案没有返回，本文不声称复原了该方案。

## 已确认的方向

- 定位：智能音乐入库助手。
- 搜索结果按歌曲、歌手和版本匹配线索排序，前三条推荐优先展示。
- 按原唱相关、翻唱、伴奏、Live 筛选。仅标题或上传者线索不足以证明原唱身份；没有证据时显示版本待确认。
- 优先考虑可处理来源，但不能把搜索结果或转换工具就绪表述为该视频已验证可下载。
- 选择试听后启动自动处理。
- 播放器固定在底部，在搜索和音乐库之间切换时保持播放，切换音源时结束上一音源。

## 当前页面需要调整的位置

1. 搜索框保留在顶部，缩短大幅介绍区。搜索结果成为搜索后的主要内容。
2. 原有粘贴视频链接入口、详细转换表单和跨平台搜索改为次要区域，保留所有能力。
3. 前三条推荐展示匹配依据、版本线索、试听与入库动作；其余结果允许展开与筛选。
4. 底部播放器使用本地音频控制；B站视频继续使用官方嵌入播放器并保留来源链接，不把视频隐藏为纯音频。
5. 所选音源对应的歌曲信息、封面候选和处理状态与当前音源绑定；切换音源时旧识别结果不能写入新音源的表单。
6. 登录、音乐库、封面编辑、云盘同步与自动喜欢验证沿用现有实现，不自动改写已有云盘文件。

## 实施前需厘清的操作边界

“选择试听后自动处理”可能指自动匹配资料、自动保存本地音频，或者自动保存并上传云盘。这三种行为涉及不同的用户操作和外部写入，不能混为一谈。已在当前会话请求用户选择其范围；在得到回答前，不改变试听按钮的下载或上传行为。

## 验收要求

- 排序在同歌名不同歌手、翻唱、现场、伴奏以及繁简字场景有明确行为；不伪造置信度与来源可用性。
- 自动识别请求延迟或失败时，保留用户的修改，提供手动纠正与重试入口。
- 固定播放器可关闭，关闭后停止音频与嵌入视频；不遮挡主要操作，支持窄屏和键盘操作。
- 搜索失败或某来源受限时保留其他来源与官方网页搜索入口。
- 新发布包保留单一 Windows 启动入口，排除私人数据，验证已打包版本的实际运行。
