# V0.7.2 音源检测修复验收

用户提供的 BV1MwYg6tEsR 在原组件和显式现有代理下均返回 HTTP Error 412；检测未获得音轨元信息，因此没有进入下载。这是实际平台响应，不能将搜索成功当成下载成功。

修复：保留并分类下载组件错误（只显示安全的类别和 HTTP 状态，避免输出地址或凭据）；检测期间每5秒报告等待时间，最长45秒后终止；任务失败信息保留在右侧，提供任务中心入口。

验证：先观察 HTTP 412 测试失败，修复后通过；停滞检测的超时和进程停止测试通过。真实指定链接在修复后准确报告 HTTP 412，没有声称下载成功。
