# Windows 单文件 EXE 分发验收

用户要求：双击 EXE 直接使用，不再解压或运行 BAT。

交付：release/CloudTune-0.7.4-Windows-x64.exe；155198464 字节；SHA256 b83ef8b923a8d38070c763b7f1d76ba3bead919d6c60da2971fbf2b9201f0458。

实现：Windows 自带 .NET Framework / WinForms 启动器，内嵌已验收的 V0.7.4 完整便携 ZIP。首次启动验证 SHA256，检查解包路径边界，原子部署到 %LOCALAPPDATA%/CloudTune/app/版本-内容摘要。后续复用组件；Node、FFmpeg、yt-dlp 和依赖全部内置。服务与用户数据仍沿用现有启动器，音乐、封面、设置和加密会话继续位于 %LOCALAPPDATA%/CloudTune/data。无需管理员权限或付费服务器。

原生启动窗口提供打开网页与退出。后台组件隐藏启动；关闭窗口通过受保护的本机停止接口结束服务，等待文件保存与任务清理，不强制终止进行中的写入。重复打开时复用已有服务。控制台不向普通用户显示。启动异常显示可读提示。

验证：smoke-exe.js 修复前因文件缺失失败；生成后通过自动解包、中文/空格用户路径、无预装运行环境、空白账号、重复启动、MP3 导入、停止后重启保留音乐、站内试听、正常停止和解包缓存复用。实际窗口模式在隐藏测试窗口下启动成功，health 返回 CloudTune 0.7.4，停止后 EXE 与后台服务退出。对仅修改嵌入 ZIP 的测试副本，完整性校验拒绝解包（退出码 1）。所有测试使用独立空白用户目录，不访问实际账号或上传云盘。

范围：Windows x64、默认浏览器网页界面；不包含 Mac 包。使用 Windows 10/11 自带 .NET Framework。EXE 暂未数字签名，分发下载时 Windows 可能显示未知发布者或信誉提示。没有关闭系统安全保护，也没有提供绕过提示的操作。

构建：node scripts/build-exe.js；发布 ZIP 必须先通过既有便携包构建与验收。
