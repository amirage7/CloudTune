目标：BV1MwYg6tEsR 的「花海」在应用中实际完成下载、MP3 转换、入库与本地试听。

诊断：最新版 yt-dlp 2026.08.19 的网页请求返回 HTTP 412；本机直连 DNS 失败。已有代理下，公开 view 与 playurl JSON 接口正常返回音轨。API 请求附带浏览器 User-Agent/Referer 时，view 返回 412；普通 Node API 请求返回 200。媒体 CDN 则使用来源 Referer。未读取浏览器登录或用户凭证。
