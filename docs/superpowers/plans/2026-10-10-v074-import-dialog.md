# V0.7.4 导入确认弹窗验收

用户目标：选择音源后不再转到右侧填写信息，点击「导入网易云」弹出确认窗口，修改歌曲信息后决定是否导入。

实现：将原右侧选定音源面板移动到原生 dialog，结果行导入按钮和播放器选择入口均打开弹窗。集中展示音源、歌名、实际演唱者、专辑、封面候选、当前账号和获取权限确认。确认按钮提交原有入库接口；取消、关闭、Esc 不提交。提交中防重复提交与关闭；失败保留表单，使用行内错误提示。未连接时从弹窗扫码，成功后恢复原表单。右侧保留同步状态与任务进度。

验证：新增三项实际页面脚本回归测试，修复前失败、修复后通过；覆盖打开不提交、修改后确认提交、校验失败保留弹窗。全量 73 项，72 通过、1 项 Unix 专用测试跳过，0 失败。最终封面占位调整后相关 4 项复测通过。

浏览器：独立空白测试库，实际搜索、点击导入、编辑歌名/演唱者、取消与 Esc；没有真实上传。默认桌面窗口与 390 × 844 窄屏检查通过，窄屏 dialog 341 × 820，底部按钮在视口内可见，正文独立滚动。截图 .packaging/import-dialog-desktop.jpg。便携包启动、账号目录隔离、音乐/封面持久化、试听和正常关闭烟雾测试通过。
