# CloudTune V0.7.4 — 智能音乐入库助手

## 下载使用（Windows）

[下载 CloudTune 0.7.4 EXE](https://github.com/amirage7/CloudTune/releases/download/v0.7.4/CloudTune-0.7.4-Windows-x64.exe) · [全部发行版](https://github.com/amirage7/CloudTune/releases)

适用于 Windows 10/11 64 位。下载 EXE 后双击，等待首次解压完成，程序会自动打开本地音乐网页。无需另装 Node.js、Python 或 FFmpeg，也无需租用服务器。联网功能需要网络连接。

使用自己的网易云账号登录；账号和音乐记录保存在当前 Windows 用户的 `%LOCALAPPDATA%\CloudTune\data`，再次启动会保留。退出时关闭 CloudTune 启动窗口，或点击窗口里的「退出 CloudTune」；仅关闭浏览器不会停止程序。

程序尚未签名，Windows 可能显示未知发布者提示。当前发行版仅支持 Windows，不能在安卓或 iPhone 上直接安装。源代码中的 `data`、下载音频、个人登录资料和构建缓存均不随仓库发布。发行版附有 SHA256 校验文件。

开发者可安装 Node.js 22 或更新版本，在项目目录执行 `npm ci`，再执行 `npm start`。重新打包 EXE：依次执行 `node scripts/download-runtime.js`、`node scripts/build-portable.js`、`node scripts/build-exe.js`；构建需要 Windows、npm、PowerShell 和系统 .NET Framework 编译器。

在 **Windows 10/11 自己电脑上运行** 的本地音乐管理网页。继承 V0.5.1 的开放音源搜索、B站视频搜索、授权音轨提取为 MP3、本地库、网易云音乐云盘上传及自动加入喜欢的重试机制。


## V0.7.4 导入确认弹窗

音源结果与播放器的导入操作打开确认弹窗，在弹窗内核对歌曲名、实际演唱者、专辑、封面候选、目标账号和保存权限。点击确认才提交；取消或 Esc 不提交，失败保留已填写的信息。未连接账号时可在弹窗发起扫码，连接后返回原来的确认窗口。右侧仅显示同步状态和任务进度。

## V0.7.3 B站下载兼容修复

视频网页检查返回 HTTP 412 时，尝试通过公开视频信息与音轨接口取得允许下载的 AAC 音轨，继续原有 MP3 转换、标签、封面与入库流程。无需读取浏览器登录信息。尊重接口返回的付费与禁止下载限制；两条路径均失败时保留明确提示。临时音轨地址只在内存短暂缓存及任务临时目录中使用，任务结束清理，不写入用户音乐库记录。已实测 BV1MwYg6tEsR 下载、入库与本地试听成功。

## V0.7.2 检测状态修复

音源检测最长45秒，期间显示等待时间。检查通过后自动下载；B站返回 HTTP 412 等拒绝时显示明确原因，未开始下载。失败信息保留在右侧任务栏，可打开任务中心重试或换音源。更清楚的提示不会改变平台拒绝请求的结果。

## V0.7.1 网络修复

通过启动入口运行时，搜索请求会使用已有 HTTP/HTTPS 代理：优先读取环境变量，其次读取 Windows 系统中已启用的手动代理。本地网页连接始终直连，不修改系统设置，不保存代理密码。PAC 自动配置和仅 SOCKS 的系统配置暂不支持；代理地址变化后需关闭运行窗口再启动。便携包内置的 Node 已支持该功能。

## V0.7 使用流程

1. 在「发现音乐」输入歌名、歌手或 B站完整视频链接。也支持已接入来源的公开音频链接。
2. 默认优先显示三条音源。版本分类、排序和匹配原因来自标题等线索；不是录音鉴定或实际音质检测。原版相关候选仍需试听核对。
3. 点击「试听」使用底部固定播放器。切换页面继续播放；试听不会下载、上传或加入喜欢。B站使用官方嵌入播放器，受平台播放限制。
4. 点击「选择此音源」，核对实际歌名、演唱者和封面。只有较明确的资料会自动补充；不明确时选候选或自行修改。UP主不直接当作演唱者。
5. 连接自己的网易云账号，确认音源使用权限，再点「一键入库网易云」。自动检查/获取音频、转 MP3、写入信息与可用封面、上传云盘，并尝试加入喜欢。
6. 在「任务中心」查看处理记录。云盘和喜欢分别核验；失败或部分完成可重试，已有本地文件会保留。重启后中断任务等待手动恢复，不会自行重新上传。

找不到封面时保留「待完善」，可在本地库手动添加。编辑已经上传的本地文件不会改变网易云中的旧文件。网易云客户端是否显示嵌入封面仍取决于客户端处理。
任务记录和登录、音乐库一样保存在当前 Windows 用户的数据目录。账号切换后不能继续其他账号的任务。关闭浏览器不会关闭本地服务。

V0.7 尚不包含音频指纹识别、实际音质评分、任意网站下载或 Mac 便携运行环境。下文保留此前本地库、封面和手动工具说明；站内播放器现在固定在底部。
## 继承的封面与本地库功能

### 1. 显示和保存真正的专辑封面

- **搜索结果缩略图**：B站搜索结果优先显示对应视频缩略图（不是歌曲专辑封面）。无法取得缩略图时显示占位符。
- **从标准曲目获取封面**：在「我的音乐库」点「信息 / 封面」→「搜索标准歌曲信息」→ 选择与实际音轨一致的歌曲候选。候选会显示 Apple 音乐目录中的专辑封面，选择后点击「保存」，会从其图片 CDN 获取 JPG/PNG 并写入本地 MP3 的 ID3 `APIC` 封面字段。
- **手动封面**：也可以在同一个弹窗里上传小于 2 MB 的 JPG / PNG 图片，保存后把它写进 MP3 并在本地音乐库展示。
- **B站下载自动匹配**：下载过程中已填写了歌名和歌手时，程序会尝试通过 Apple 曲库找到**歌名和歌手均严格匹配**的专辑封面；找不到或网络请求失败时仍会完成音频保存，用户可稍后手动选择。
- 本地封面文件存放在 `data/covers/`，音频保存在 `data/tracks/`；MP3 封面同时嵌入音频文件内部。非 MP3 格式的封面可在 CloudTune 中显示，但不写入原音频标签。
- Apple 曲库信息和封面可能不包含所有中文歌曲、非正式版本或现场演出。请**确认具体演唱版本**，不要把视频缩略图或翻唱误认为原唱专辑封面。

**已上传网易云的音乐：** 编辑本地封面不会自动改变网易云云盘中的旧文件，不能保证网易云读取/显示 APIC。更改已经上传的版本，需在网易云客户端纠正信息，或按需手动处理旧文件后上传新版本；程序不擅自覆盖或重复上传。

### 2. 无需每首歌反复勾选

B站 MP3 转换界面移除了此前“我确认拥有下载权限”的必勾复选框，转换操作不再依赖这一项。页面保留一段简短的权限说明；**仍请仅处理自己有权下载、保存和使用的音轨**。不提供付费/DRM 破解、绕过登录限制等功能。

### 3. 在 CloudTune 里试听

- **B站视频**：搜索结果点击「▶ 站内试听」，会在 CloudTune 的弹窗中打开**B站官方嵌入播放器**，无需默认跳转至另一个网页。弹窗关闭时播放器会停止。
- **本地音乐**：进入「我的音乐库」点击「▶ 试听」，打开 HTML5 音频播放器。后端支持 HTTP 字节范围请求，以便拖动进度条或快速定位。
- **平台限制**：B站可能限制第三方网页嵌入、要求登录或禁止播放。CloudTune 不会绕过这些限制。如果嵌入播放器无法播放，弹窗保留备用官方页面链接。嵌入的仍是视频画面（不是无需下载的纯音频流）。

## 安装与从 V0.5.1 升级

1. 下载 `CloudTune-0.7.4-Windows-x64.zip` 并解压全部文件。**不要直接在压缩包内运行**。
2. 双击「启动 CloudTune.bat」，服务就绪后会自动打开浏览器。便携包已包含 Node、依赖、yt-dlp 和 FFmpeg，无需安装组件或购买服务器。
3. 使用结束关闭启动时出现的 CloudTune 运行窗口，或在该窗口按 Ctrl+C 正常停止服务。无需双击其他文件。只关闭浏览器标签页不会停止本地服务；重复启动会复用现有服务。发布包只保留「启动 CloudTune.bat」一个入口。
4. 旧版升级先停止旧服务。将完整旧 `data/` 复制到新解压目录，首次启动会复制迁移，原文件仍保留；也可在已更新的旧项目中启动一次完成迁移。
5. 此后数据固定保存在 `%LOCALAPPDATA%\CloudTune\data`，换新版文件夹不影响音乐、封面、设置和同一 Windows 用户的加密登录。已有固定用户数据时不会被旧 data 覆盖。

账号和音乐库按 Windows 用户隔离；同一个 Windows 账户共用一份记录。手机不能直接运行该 Windows 包。服务只监听本机地址，使用自动分配的空闲端口，具体地址显示在启动窗口。

分享时直接分享发布 ZIP。构建使用文件白名单和干净依赖，不包含开发者的 data、登录或音乐。第三方许可与工具来源保存在 `third-party/`。开发者构建：先执行 `node scripts/download-runtime.js` 下载、校验和解压运行组件，再执行 `node scripts/build-portable.js`。构建脚本依赖开发电脑上的 Node、npm 和 PowerShell，终端用户无需安装这些开发工具。

开发者也可以在源码目录执行以下命令（`npm start` 使用项目内 data 和 4173 端口）：

```powershell
npm install
npm start
```

自动化测试：

```powershell
npm test
```

## 新版典型用法

1. 搜索歌曲 → B站视频结果点击「▶ 站内试听」确定版本。
2. 若你有该音轨的下载保存权限，选择「填写信息并转 MP3」，确认正确的歌曲名和歌手；也可将 BV 视频完整链接粘贴到顶部表单。
3. 转换后打开「我的音乐库」，如果封面缺失，点击「信息 / 封面」，从 Apple 曲库选择匹配歌曲或上传图片。
4. 保存本地 MP3 标签后，点击「上传云盘」。网易云账号登录、自动喜欢和待核实重试逻辑均沿用 V0.5.1。
5. 点击音乐库中的「▶ 试听」可播放本地歌曲。

## 技术与限制

- 仍是 **本机运行的 Node.js 服务 + 网页前端**，不是可以直接部署的纯静态网页。
- 网易云登录凭证使用 Windows DPAPI 加密后保存在 `data/session.json`，仅当前 Windows 用户可以解密。扫码或会话连接成功后自动保存，重启自动恢复；退出连接会清除保存的登录。会话过期需重新登录，临时断网不会删除登录记录。只监听 `127.0.0.1`。**不要把端口直接暴露公网。**
- 专辑封面的网络获取只接受 Apple 与网易云曲库图片 CDN 的 HTTPS 地址，限制 2 MB，拒绝其他网址，防止服务端任意 URL 请求；上传封面严格检查图片内容是 PNG/JPG。
- 搜索仍可能因网络代理、接口风控失败；B站嵌入播放不保证所有视频正常播放。
- 网易云第三方接口可能变化。云盘与喜欢列表的同步仍需在个人设备上实测；接口成功不保证手机客户端最终显示。已上传 MP3 的封面不会自动回写。
- 程序不会让视频观看链接自动等于可下载音频权限。请遵守原平台和权利人的许可。

此项目为个人音乐管理工具，与 B站、Apple 和网易云音乐均无关联。

## 记住登录与音乐库

- 更新程序后首次登录一次，之后使用同一 Windows 用户双击「启动 CloudTune.bat」即可恢复登录。无需每次扫码；网易云主动使会话失效时仍需重新登录。
- 已下载或导入的音乐、封面、歌曲信息和设置继续保存在 data/，重启后会在「我的音乐库」显示。退出网易云连接不会删除音乐。
- 更新或移动项目时请保留完整 data/ 文件夹；不要删除它。复制到另一台电脑或另一 Windows 用户后音乐仍可保留，但加密登录需要重新建立。
- 重启会保留已经完成的音乐文件，不会自动续跑关闭前尚未完成的转换任务。
- 登录恢复目前针对 Windows 10/11。登录凭证不会通过页面接口返回，也不写入浏览器存储。

## 自动识别歌名、歌手与封面

- 点击 B站结果的「填写信息并转 MP3」后，自动读取公开视频标题与简介，联网查询 Apple 和网易云音乐目录，预填歌名、歌手和匹配封面。粘贴链接后也可点击「自动识别歌名 / 歌手 / 封面」。
- 音乐库的「信息 / 封面」打开后自动查询候选；确认或修改后点击保存。识别过程不会自动覆盖磁盘文件，也不会自动上传。手动编辑中的文本会保留。
- 这是视频资料与曲库匹配，不是听音识曲。不把 UP主直接当歌手；对同名歌曲、翻唱和现场版保留候选与待确认提示。没有同一演唱版本封面时不套用另一歌手的封面，可手动选择或上传。
- 封面预览通过本机服务获取 Apple / 网易云批准的 HTTPS 图片，保存后写入封面文件，MP3 同时嵌入 APIC 标签。更改歌名或歌手后不会直接沿用转换前已选的另一曲目封面。
- 已上传的网易云云盘旧文件不会被自动改写。

### 视频人名交叉匹配改进

识别会保留视频标题中的人名并剔除无损、4K 等宣传词，读取简介中的演唱者与原唱身份，区分作词、作曲及 UP主。先检索同名演唱版本，再用歌名加人名进行定向查询。Apple 中国区无结果时查询香港、台湾目录，统一简繁体后匹配。页面显示匹配依据和可打开的来源链接，所有预填仍需用户确认。升级后启动 BAT 会自动安装新增加的简繁转换依赖。
