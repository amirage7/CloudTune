扫码失败？试试网页登录会话连接

仅用于你自己的账号。先在 网易云官方网站 ↗ 登录，再在浏览器开发者工具的 Application / 应用 → Cookies → music.163.com 中找到 MUSIC_U，只复制这一项到下方。仅提交到本机 127.0.0.1，验证成功后加密保存；点击退出连接可清除。

登录 Cookie 相当于账号通行证。不要发到聊天、截图、网盘或陌生网站，也不要在公共电脑使用。会话可能失效，且第三方上传接口仍可能被网易云限制。

B站 MP3 转换组件

运行状态：检查中…。需要 yt-dlp 与 FFmpeg，CloudTune 不会自动安装第三方可执行程序，也不需要你的 B站登录凭证。

在 Windows PowerShell 中安装：

winget install --source winget --id yt-dlp.yt-dlp
winget install --source winget --id Gyan.FFmpeg

安装后重启 CloudTune。或从 yt-dlp 官方发布页 ↗ 下载 yt-dlp.exe，从 FFmpeg 构建页 ↗ 获取 ffmpeg.exe、ffprobe.exe，放到项目 tools/ 文件夹。MP3 的码率无法超过原视频音质。

♥

自动加入「我喜欢的音乐」

每次成功上传云盘后，尝试把同一首云盘歌曲加入当前网易云账号的喜欢列表，并重新读取喜欢列表核验。无法定位歌曲 ID 或验证失败会显示「待核实」，可从音乐库单独重试。

仅对上传成功的歌曲执行；云盘与喜欢是两个独立步骤。网易云可能无法正常播放某些云盘歌曲。切换选项不会删除现有收藏。

B站搜索说明

本工具会尝试调用 B站的公开搜索接口获取标题、UP主、版本等视频信息；接口若限制自动请求，可通过顶部 B站搜索入口在官方页面继续查看。用户确认有下载权时可使用 yt-dlp 与 FFmpeg 提取 MP3，不使用你的 B站 Cookie，不处理受访问限制的内容。

如果其它音源提示 fetch failed，优先检查本机 Node.js 到对应平台的网络和代理设置。即使修好网络，开放许可音源也未必包含商业流行歌曲。

⛨

关于音频来源

工具只接入具有公开下载方式的音频来源。使用前请确认具体文件许可要求（署名、商业用途限制等）。搜不到某首商业歌曲属于正常情况，并不代表程序故障。
